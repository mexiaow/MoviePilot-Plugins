# Emby入库日报

定时统计 MoviePilot 入库记录，通过 Telegram Bot 发送到指定群组或话题。

插件不启动 Telegram 长轮询，也不提供交互命令。它只在 cron 触发或手动“立即发送一次”时生成日报并调用 Telegram Bot API。

## 配置

| 配置项 | 说明 |
| --- | --- |
| 启用插件 | 开启后按 cron 定时发送 |
| 立即发送一次 | 保存配置后立即生成并发送一次，发送后自动关闭 |
| 只统计成功入库 | 默认开启，只统计转移成功的历史记录 |
| Bot Token | Telegram Bot Token |
| Telegram API 地址 | 默认 `https://api.telegram.org`，有反代时填写基础地址 |
| Chat ID | Telegram 群组或频道 ID |
| 话题 ID | `message_thread_id`，留空或 0 时发送到默认话题 |
| 执行周期 | 5 位 cron 表达式，例如 `45 23 * * *` |
| 查询数量 | 每次最多统计多少条入库记录 |

## 发送内容

日报按电影、剧集、动漫分组，展示标题、季集与文件大小。

分类规则：二级分类为 `国漫`、`日漫`、`日番` 时归入动漫；类型为电影时归入电影；其余归入剧集。

## 注意事项

- 定时任务使用 MoviePilot 插件服务调度（cron）。
- 插件直接读取 MoviePilot 转移历史，无需填写 API 地址或 Token。
- 消息使用 HTML 模式，媒体标题中的特殊字符会被转义。
- 日报过长时按行拆分为多条消息发送。
